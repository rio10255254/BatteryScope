## Two fixes from the G14's own data

- **The quick test could get stuck for hours.** On the G14's OLED panel the brightness setting does not take effect. The test treated that as "another program changed it" and set it again every 2 seconds, for three hours, until the battery was nearly empty. A setting that cannot be set is now given up at once and restored, and the test moves on to the next step. A setting that is set but does not hold is given up after five tries.
- **Protection mode did not switch on after updating.** A crash that an earlier version had already listed was not counted as new, so 0.23.2 stayed out of protection mode. It now compares the newest crash on record with the last one it acted on.

建議：更新後如果 24 小時內當過機，會進入保護模式；照「穩定性」頁的「下一步」做完睡眠測試再恢復。
