## Performance on the home tab, with fan and power presets; the battery tab gathers everything about the battery

**Home is now a performance dashboard (Perf tab):**
- A battery line: charge, power draw and time left.
- The performance mode as one row of choices. On ASUS laptops: automatic, silent, balanced or turbo. On other PCs: the Windows power mode for the current source.
- CPU temperature, clock (as Task Manager shows it), load and power, with a 5-minute chart.
- Integrated GPU use, and the discrete GPU's state: Eco, asleep or in use, with the programs using it. Its temperature, clock, power and load come from NVIDIA's driver only while it is already awake, so it is never woken just to show a number.
- Fan speeds and a **fan mode** (ASUS): factory, quiet, standard or strong. Each uses the firmware's own curve of a mode (silent, balanced, turbo), not made-up curves.
- A **CPU power limit** (ASUS): factory, 15 W, 25 W or 45 W sustained. Each stays at or below the balanced mode.
- Quick switches: 60 Hz on battery, CPU Boost on battery, dynamic saving, keyboard backlight.

The firmware resets fans and power limits whenever the performance mode changes, so BatteryScope writes them again after every change: fans after 0.1 s and limits after 1.1 s, as G-Helper times it. Choosing "factory" switches to another mode and back, G-Helper's workaround for the G14 2024 keeping custom limits, which restores both.

**The battery tab** now holds the battery cards, the 30-minute chart and the program ranking (formerly the Apps tab). Clicking the battery cards opens history, health, the charge limit and exports.
