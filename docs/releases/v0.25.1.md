## The control check no longer leaves a power limit behind

On the G14 with BIOS 311, the control check's power-limit test set 15/20/25 W and then could not take it away again. Switching the performance mode away and back (how G-Helper resets limits) leaves the limit in place on this BIOS; only a restart clears it.

- When a check finds the limit still in force, BatteryScope remembers it for this model and BIOS. Later checks do not write the test limit again, and the power limit presets are not offered. A BIOS update tests it again.
- Until the next restart, the Perf page shows a banner that the CPU is still held at 15 W, and the problem report says so too, instead of "factory".
- A check run with an earlier version that left the limit is recognised after updating.
- The check's description now says up front that the power limit test sets 15 W for a moment.

建議：更新後「重新啟動」電腦一次（不是關機），清掉上次檢查留下的 15 W 上限；之後再按檢查也不會再寫入功耗上限。
