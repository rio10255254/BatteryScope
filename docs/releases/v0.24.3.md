## A heavier test load for the control check

After a restart, the G14 drew about 20 W under the check's all-core load before anything was written, and the same in silent and in turbo. So the 20 W was not a leftover power limit. The test load was too light: it stayed far under every mode's limit, so no mode could show a difference.

- The load now runs eight independent chains of packed arithmetic per thread, so the processor draws what its limits allow.
- The baseline row also shows whether the power plan has CPU Boost switched off while plugged in.

Fan curves: the firmware returns all zeros on this model, so the fan mode stays unavailable there.
