## Redesign, pixel style, power modes, and much more

BatteryScope 0.10.0 is a full redesign. The panel offers dark, light, and high-contrast themes with a default pixel style (an embedded Cubic 11 subset under SIL OFL 1.1, falling back to the system font for anything it lacks), app icons in the ranking, a battery-percentage tray icon, and a pixel battery buddy that reacts to the battery state.

The old battery-only Save button is replaced by a power mode page that sets the Plugged in and On battery modes separately and shows the mode Windows actually applies. New: battery health and cycle count, remaining-time ranges, a learned charging curve and charge-limit detection, cycle-weighted CPU attribution, per-app GPU use, session energy, a local-only 7-day history with a daily grade and achievements, sleep drain detection, minutes gained if an app is closed, per-app Efficiency mode, automatic power mode rules, background-drain, low-battery, sleep, and charge reminders, CSV export, a shareable summary card, and a mini floating window.

Requires Windows 10 version 1703 or later (built and tested for Windows 11 x64). The EXE is portable and needs no installer or administrator rights; it is not code-signed, so Windows SmartScreen may ask for confirmation the first time (More info → Run anyway).

Validation: the Windows CI build runs the full core and isolated panel test suites with MSVC; 143 core tests and 92 panel checks also pass under Wine. Not yet verified on real hardware: the accuracy gain from cycle weighting, charge-curve learning, GPU counters, sleep detection, automatic power mode switching, and notifications.
