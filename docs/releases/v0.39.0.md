## Fan control: presets and G-Helper-style custom curves

Until now BatteryScope only showed the fan speeds on the G14 2024: its fan mode appeared only where the firmware hands out its own curves, and this model's firmware returns zeros. Fan curves can still be written there (as G-Helper does), so both kinds of control are now available on a **Fans** page (Performance → 風扇).

- **Presets:** Factory, Quiet, Standard, Strong. Where the firmware hands out its curves they are the firmware's own curves of silent, balanced and turbo; where it does not, BatteryScope's own three.
- **Custom curves, as G-Helper has them:** one 8-point curve for each fan (CPU, GPU, and a middle fan where there is one) in each performance mode (silent, balanced, turbo).
  - Drag a point; the others move to keep the curve in order (a point moved up lifts the ones after it, moved down lowers the ones before it).
  - Or select the curve and use the keyboard: Left/Right choose a point, Up/Down move it 1% (Shift: 5%), Ctrl+Left/Right move it 1 °C (Shift: 5 °C). Tab moves on.
  - The readout shows the chosen point exactly (e.g. "Point 4: 65 °C → 25%") and, live, the temperature now, the speed the curve asks for there and the fan's RPM; a marker on the chart shows where the temperature is.
  - "Reset this curve" and "Use for all three modes".
- **Safety limits**, kept by every curve that is written: temperatures rise within 20–110 °C, speed never falls as the temperature rises, and points at 90 °C and above, and the last point, run at 50% or more. The area this keeps off-limits is tinted on the chart. 100% is written as 99%, as G-Helper writes it.
- Curves are written again after every performance mode change (the firmware resets them), on wake and at start. A curve edited for the mode in use takes effect at once; one edited for another mode takes effect when that mode is chosen.
- The Performance page's row now reads "Fans" and opens the page; Esc goes back.
