## Automatic mode: saving only on battery, balanced when plugged in

- **On battery, automatic mode only saves.** Every activity, heavy work included, runs in efficiency with CPU Boost off and the firmware's silent mode.
- **Plugged in, automatic mode is the balanced mode**, with CPU Boost at efficient enabled (no boost in light use, boost when a load lasts) and the Windows balanced power mode. A mode chosen by hand is left alone.
- **Balanced no longer holds the CPU at its base clock** when plugged in: its Boost was "off" (about 18 W under full load on the G14) and is now efficient enabled. The menu offers that value for every mode.

This replaces 0.35.0, which was never released: it switched Boost on for heavy work on battery, the opposite of what was wanted.
