## Fixes from the first control check on a real G14

The first run of the control check showed three problems in the check itself:

- **Brightness read as 0% while the panel was at 60%.** The level was read through PowerShell, and came out as 0 whenever PowerShell printed a progress record first. Brightness is now read and set through WMI directly, on the active panel. The earlier conclusion that this panel ignores brightness changes is withdrawn until it is checked again.
- **Performance mode and power limit showed "no effect" with the same 19.3 W three times.** That looks like the test load itself being held back, not three equal limits. The load now runs with Windows' efficiency throttling switched off, and its clock is recorded. A load that stays far under the base clock, or under the limit being tested, is reported as "unclear", not "no effect".
- **Fan curves are reported as unsupported on this model.** The diagnostic dump and the report now include the raw curves the firmware hands out. The fan mode row is shown only where curves are supported.

建議：更新後插著電、把 Windows 電源模式設成「平衡」或「效能」，再按一次「檢查每項控制是否真的有作用」，然後建立回報包傳給開發者（裡面會有風扇曲線的原始資料）。
