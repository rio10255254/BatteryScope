## The control check now proves that what it changes is put back

The second control check on the G14 showed the CPU held at about 19 W under a full all-core load, in every performance mode. Either a power limit written by the first check was never cleared, or something else (such as a low-wattage charger) was already limiting the PC. The data cannot tell which, so the check now finds out for itself:

- **A baseline first.** The all-core load is measured before anything is written.
- **No pointless writes.** If the turbo load already draws less than 28 W, the power limit is not written at all, since nothing could be measured.
- **Restore is verified.** After the power-limit test is set back to factory, the load is measured once more. If it does not come back to at least 88% of what it was, the check reports that the limit is still in force, asks for a restart, and switches the power limit option off on this PC.

Also fixed:
- **Fan curves could not be read on this model.** The firmware's answer is longer than 16 bytes, and the "more data" reply was taken for a failure. The first 16 bytes are now used, as G-Helper does.

建議：請先「重新開機」（清掉可能殘留的功耗上限），接上原廠變壓器，更新後再按一次「檢查每項控制是否真的有作用」，然後建立回報包。
