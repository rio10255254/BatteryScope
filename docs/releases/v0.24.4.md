## The control check switches CPU Boost on while it measures

The G14's power plan has CPU Boost switched off while plugged in. With boost off the clock stops at the base clock, and an all-core load draws only 13 to 20 W. That is under every performance mode's limit, so silent and turbo looked the same.

- For the load tests, the check now switches CPU Boost on for the current power source and puts it back afterwards.
- The baseline row says when boost was off and had to be switched on.

建議：更新後再按一次「檢查每項控制是否真的有作用」。這次會暫時打開 CPU Boost，風扇會比之前吵幾秒，量完會自動關回去。
