## Installer, automatic cleanup of older copies, and update reminders

BatteryScope 0.12.0 adds an installer, `BatteryScope-0.12.0-setup.exe`, next to the portable zip.

- **Per-user install, no administrator rights**, always into `%LOCALAPPDATA%\Programs\BatteryScope`, with a Start menu shortcut, optional desktop shortcut and launch at sign-in, and an uninstaller in Settings → Apps.
- **Older copies are closed first.** The installer closes any running BatteryScope (installed or portable, any version): cleanly first so it undoes its efficiency and power mode changes, then by force.
- **Shortcuts and pins follow the latest version.** Because the folder never changes, Start menu and desktop shortcuts, taskbar pins, and launch at sign-in keep working after every update. Installing also repoints shortcuts, taskbar pins, Windows 10 Start pins, and launch at sign-in that still open an older `BatteryScope.exe` elsewhere, such as a portable copy.
- **Update reminders.** Once a day BatteryScope reads the latest version from GitHub and shows one notification per new release. Clicking it downloads the installer, verifies its SHA-256, installs, and reopens BatteryScope; on a mismatch nothing runs. Turn it off or check now under ⋯ → Updates. No usage data is sent.

Validation: every Windows CI build installs over a running "old portable" copy and checks that it closed, that its shortcut, taskbar pin and sign-in entry moved to the installed copy, that an update keeps the same folder with one running copy, and that uninstalling removes the program and its sign-in entry. The in-app download-and-install path can only be exercised end to end once a later release exists.

建議下載安裝版 BatteryScope-0.12.0-setup.exe（不需要管理員權限）。安裝時會自動關閉正在執行的舊版（包括免安裝版），並把桌面捷徑、工作列釘選與登入啟動改指向安裝版；之後每次更新都安裝在同一個位置，捷徑與釘選不用重設。BatteryScope 每天會檢查一次新版本，有新版時跳出通知，點通知即可下載、校驗並自動安裝（可在「⋯ → 更新」關閉）。首次執行若出現 SmartScreen，請點「其他資訊 → 仍要執行」。附有 SHA-256 校驗檔。
