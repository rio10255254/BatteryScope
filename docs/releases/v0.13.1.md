## One-click export from the power lab

**⋯ → Power lab → Export (zip + copy summary)** zips the lab folder (daily CSV traces, experiment blocks, G-Helper config copies, and a summary) to the desktop and copies the summary to the clipboard, ready to paste into a message. It uses the `tar.exe` built into Windows 10 1803 and later; if that is unavailable, the folder opens instead and the summary is still copied.

「⋯ → 省電實驗室 → 一鍵匯出（壓縮檔＋複製摘要）」會把實驗室資料夾壓縮到桌面，並把摘要複製到剪貼簿，可直接貼到訊息裡。
