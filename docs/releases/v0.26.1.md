## The 15 W limit went away without a restart; the check now measures the Windows power mode

The 13:28 check left a 15/20/25 W limit on the G14, and BatteryScope then said only a restart would clear it. The 14:18 report shows the same boot, with no sleep and no unplugging in between. Yet the CPU drew 46.9 W, so the limit was gone. Between the two checks, nothing touched the firmware. BatteryScope did set the power plan again (writing CPU Boost) and switched the Windows power mode. The platform appears to re-apply its limits then.

- **"Still at 15 W" follows what is measured.** The notice clears by itself once the CPU draws more than 25 W, or a check's baseline does. The notice also has an "Apply again" button, which sets the power plan and the Windows power mode once more.
- **The control check measures the Windows power mode under load.** It compares best efficiency with best performance on the same all-core load. This shows whether the CPU's power follows the Windows power mode on this PC, which mode link switches along with the performance mode.
- **The ASUS mode is no longer called "no effect"** when the CPU barely changes. In this check the CPU drew 40.8 W in silent and 42.8 W in turbo. The firmware mode also sets the fan curves and the GPU's power, which a short CPU load does not show, so it is reported as inconclusive with that explanation.
- **After the power-limit test, the check also re-applies the power plan,** which seems to be what lifted the limit on the G14.
- **Mode link writes its Windows power mode change into the black box.**
