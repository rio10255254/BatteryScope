## One header row, a one-line warning, and an interface diagnostic

Built from the design that was agreed first.

- **One header row.** The page's name on the left; the power mode key, the menu and hide on the right, level with each other. The "BatteryScope" wordmark, the subtitle and the mascot are gone, and every page starts higher: the lists and pages gain that room.
- **A one-line warning.** The crash notice on the Performance tab was a title, two lines and a button. It is one row now: an indicator, what is the matter, and where it leads.
- **Interface diagnostic** (⋯ → Tools). It opens each tab in turn, twice, and records when every frame came and how long it took, with the display's refresh rate. The result is `BatteryScope-ui-diagnostic.txt` on the desktop. It records timing only.

Not in this version yet, though they are in the design: the three CPU tiles, the Battery tab's buttons appearing only for a selected program, and 16-point margins everywhere.

請在 G14 上執行一次「⋯ → 工具 → 介面診斷」，把桌面上的 BatteryScope-ui-diagnostic.txt 傳給我：有了每一格的時間，動畫哪裡不順就能對症處理。
