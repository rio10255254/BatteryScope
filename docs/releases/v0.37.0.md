## Power mode and program details in the same design

- **Power mode page.** What is in effect, then a row of three choices for each power source (the lit key is the current mode), then the commands and the explanation, set out like every other page. A source that cannot be changed shows its mode as text instead of greyed buttons.
- **Program details page.** The name, PID and path on top; CPU, estimated watts and memory in three small wells; efficiency mode as a switch and the dynamic saving rule as a row; usage and the CPU energy estimate under their own headings; the long explanation of how the estimate is made folds away until opened.
- Both pages now use the dot-matrix font, the slim scroll indicator and the page-arrival animation; the plain text box with the Windows scroll bar is gone from them.
