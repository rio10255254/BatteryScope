## The 30-minute chart is back on the main panel

Since 0.18 added the tabs, the main panel worked out its layout two ways. Painting measured the height above the tabs and treated the default panel as a compact one, so it left out the 30-minute power chart. The list was still placed as if the chart were there, which left an empty gap between the battery cards and the ranking. Both now use the same measure, so the chart is back and the gap is gone. The panel self-test checks it.

建議：更新後主面板的電池卡片下方會重新出現 30 分鐘耗電圖，不再有空白。
