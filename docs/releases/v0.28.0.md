## A clean, macOS-like look; the pixel style stays as an option

The panel now looks and moves like a macOS app by default. The pixel style is unchanged and one click away in Settings → Style.

**Look**

- macOS system colours: window grey, a lighter content area, white grouped rows (graphite in dark mode), label and secondary-label greys, and the system blue accent. Warnings and errors use the system orange and red.
- Settings rows that follow one another form one rounded list with hairline separators, as in System Settings. A row's value is plain grey text beside the chevron.
- Section titles are plain bold labels; page titles are larger and bold, without a rule under them.
- Switches are capsules that fill with the accent, with a white knob and a soft shadow.
- The performance mode and the tab bar are segmented controls: a raised thumb on a grey track.
- Menus highlight the row in the accent colour with white text and mark the chosen option with a check.
- Meters are thinner, tags are capsules, and the battery mascot (a pixel sprite) shows in the pixel style only.

**Motion**

- Switches, the segmented control and the tab bar move on a lightly damped spring: quick, with one small overshoot, as macOS does.
- Hover and press darken a row instead of shrinking it.
- Everything still stops when Windows is set to reduce animations.

Updating switches to the new style once; choose Pixel in Settings → Style to go back.

建議：更新後介面會換成新的簡約風格；想用原本的像素風格，到「設定 → 外觀 → 風格」切回「像素」即可。
